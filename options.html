Journey Sidebar の設定

Zapierで「Webhooks by Zapier（Catch Hook）」をトリガー、「Journey: Create Journal Entry」を アクションとするZapを作成し、発行されたWebhook URLをここに貼り付けてください。

Zap設定の手順（初回のみ）

  1. Zapierで新しいZapを作成し、トリガーに「Webhooks by Zapier」→「Catch Hook」を選択する。
  2. 表示されたWebhook URLをコピーし、上のフィールドに貼り付けて保存する。
  3. このページで「テスト送信」を押し、Zapier側の「Test trigger」でデータを受信する。
  4. アクションに Journey アプリの「Create Journal Entry」を選び、受信した text フィールドをJourney側の「テキスト」欄にマッピングする。
  5. Zapを有効化（On）にする。

送信されるJSONのフィールドは text のみです（ Journey公式のZapier用APIドキュメント に準拠）。太字・斜体・箇条書き・番号付きリストを使った場合は、Journeyが対応している タグ（h1, b, strong, i, em, br, ul, ol, li）だけを使い、全体を <html>...</html> で囲んだ文字列になります。書式を使わなかった 場合はそのままのプレーンテキストです。タイトル欄に入力した内容は <h1> として本文の先頭に埋め込まれます（Journeyには独立したタイトル項目がないため）。
