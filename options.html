Journey Sidebar の設定

既定値は Journey Web App のタイムラインページです。ログインページから始めたい場合や、 別の言語/地域のURLを使いたい場合はここを変更してください。

なぜ「サイドパネル」ではなく別ウィンドウなのか

Journey は自身が iframe（他ページへの埋め込み）内で表示されていることを検知すると、 「clickjacked の可能性があります」という警告を表示し、編集機能を無効化します。 そのため、ブラウザのサイドパネルに直接埋め込む方式は使えません。 この拡張機能では代わりに、通常のブラウザウィンドウとして Journey を開き、 画面の右端にドッキングさせることでサイドバーのように使えるようにしています。 通常のウィンドウとして開くため、Journey側の機能はすべて問題なく利用できます。
