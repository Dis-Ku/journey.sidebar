# Journey Sidebar

Edge のサイドバー機能廃止に伴う代替として、ブラウザのサイドパネルにオンライン日記アプリ
[Journey](https://journey.cloud/) を常時表示できるようにする、Chrome/Edge 用の拡張機能（Manifest V3）です。

## 主な機能

- ツールバーのアイコンをクリックすると、ブラウザ標準の**サイドパネル**に Journey の Web アプリが開きます（Edge・Chrome 共通の `sidePanel` API を使用）。
- サイドパネル上部のツールバー
  - 🏠 ホーム: 設定したURLへ戻る
  - ⟳ 再読み込み
  - ↗ 新しいタブで開く
  - ⚙ 設定（表示するURLを変更）
- 表示するURLは設定画面から変更可能（既定値: Journey Web App のログインページ）。

## インストール方法（開発者モードで読み込み）

1. このフォルダをダウンロード（またはクローン）します。
2. Edge または Chrome で `edge://extensions` （Chromeなら `chrome://extensions`）を開きます。
3. 右上の「開発者モード」を有効にします。
4. 「展開して読み込み（unpacked）」からこのフォルダを選択します。
5. ツールバーに表示されたアイコンをクリックするとサイドパネルが開きます。

サイドパネルは、ツールバーアイコンの右クリック→「サイドバーに固定」（ブラウザにより文言は異なります）などで
常時表示のように使うこともできます。

## 表示URLの変更

拡張機能のアイコンを右クリック→「オプション」、またはサイドパネル内の ⚙ ボタンから設定画面を開き、
表示したいURLを入力して保存してください。地域や言語によって Journey Web App の URL が異なる場合や、
将来 Journey 側の URL が変更された場合はここで調整できます。

## 仕組みと注意点（重要）

多くの Web サイトは `X-Frame-Options` や `Content-Security-Policy: frame-ancestors` という
レスポンスヘッダーによって、他サイト（iframe）からの埋め込み表示をブロックしています。
Journey も同様の設定がされている可能性があります。

この拡張機能では `declarativeNetRequest` を使い、**あなた自身のブラウザ内でのみ**、
設定したドメイン（既定は `journey.cloud`）からの応答に含まれるこれらのヘッダーを取り除くことで、
サイドパネル内への埋め込み表示を可能にしています。

- 通信内容が外部のサーバーに送信されたり、書き換えられて記録されたりすることはありません。
  あくまでブラウザのレンダリング挙動（フレーム内表示を許可するかどうか）に関わるヘッダーを、
  ローカルのルールで取り除いているだけです。
- `journey.cloud` 以外のドメインを設定画面で指定した場合は、そのドメインに対する追加の権限を
  ブラウザがユーザーに確認します（許可した場合のみ、そのドメインにも同様の処理が適用されます）。
- Journey 側の実装変更（埋め込み自体を検知してブロックする等）によっては、将来的にうまく
  表示できなくなる可能性があります。その場合はサイドパネル下部の「新しいタブで開く」を使ってください。

## クロスオリジンによる制約

サイドパネル内の Journey は別ドメイン（クロスオリジン）で動作するため、拡張機能側からその
ページの内容やログイン状態を読み取ることはできません（Journey 側のログイン情報を拡張機能が
取得・保存することもありません）。ログイン状態は通常の Cookie の仕組みにより、ブラウザに
保存されます。

## ファイル構成

```
manifest.json     拡張機能の定義（Manifest V3）
background.js     サービスワーカー（サイドパネルの開閉挙動、動的ルールの同期）
sidepanel.html/js/css  サイドパネルのUI（iframeでJourneyを表示）
options.html/js/css    表示URLを変更する設定画面
common.js         共通定数（既定URL・ストレージキーなど）
rules.json        journey.cloud 向けの declarativeNetRequest 静的ルール
icons/            ツールバー用アイコン
```
