# Journey Sidebar

Edge のサイドバー機能廃止に伴う代替として、ブラウザの**サイドパネル**に簡易日記エディタを表示し、
書いた内容をJourney公式の**メール投稿機能**経由でオンライン日記アプリ
[Journey](https://journey.cloud/) に送信する、Chrome/Edge 用の拡張機能（Manifest V3）です。

## これまでの試行錯誤（経緯）

1. **iframe埋め込み案**: JourneyのWebアプリをサイドパネルに `<iframe>` で直接埋め込む方式を
   試みましたが、Journeyは自身がiframe内に表示されていることをJavaScriptで検知すると
   「You may have been clickjacked」という警告を出し、編集機能そのものを無効化する仕組みを
   持っていることが分かりました。ブラウザが保護している`window.top`などの仕組みに依存した
   Journey側の正当なセキュリティ対策であり、拡張機能側から回避することはできません。
2. **Zapier Webhook案**: 独自の簡易エディタをサイドパネルに置き、
   [Journey公式のZapier用APIドキュメント](https://support.journey.cloud/ja/categories/web-services/articles/journey-api-documentation-for-zapier)
   に従って「Webhooks by Zapier」経由でエントリーを送信する方式を実装しましたが、Zapierの
   無料プランでは「Webhooks by Zapier」が有料プラン限定機能（Premium）になっており、追加費用
   なしでは使えないことが判明しました。
3. **メール投稿案（現在の方式）**: Journeyには、専用のメールアドレス宛にメールを送ると
   自動的に日記エントリーになる公式機能があります。追加費用や外部サービスの登録が不要なため、
   これを採用しました。

## 主な機能

- ツールバーのアイコンをクリックすると、ブラウザ標準の**サイドパネル**が開き（もう一度クリック
  すると閉じます）、タイトル・本文を入力できるシンプルなエディタが表示されます。
- 本文は太字・斜体・箇条書き・番号付きリストに対応した簡易リッチテキストエディタです
  （`contenteditable` + ブラウザ標準の書式コマンドのみで実装しており、外部ライブラリは
  読み込んでいません）。
- 入力内容は自動的に下書き保存されます。実際にメールが送信されたかは拡張機能側から確認
  できないため、下書きは自動では消去されず、「下書きを消去」ボタンで手動で消します。
- 「Journeyに送信」を押すと、設定したメールアドレス宛のメール作成画面が新しいタブ／
  メールソフトで開きます（件名＝タイトル、本文＝エントリー本文）。あとはメールソフト側で
  送信するだけです。

## セットアップ

### 1. 拡張機能の読み込み

1. このフォルダをダウンロード（またはクローン）します。
2. Edge または Chrome で `edge://extensions` （Chromeなら `chrome://extensions`）を開きます。
3. 右上の「開発者モード」を有効にします。
4. 「展開して読み込み（unpacked）」からこのフォルダを選択します。

### 2. Journeyの投稿用メールアドレスを確認

1. Journeyアプリ（Web/スマホ/PC）の設定画面を開き、「メールで投稿」「Post via Email」に
   相当する項目を探します（バージョンにより表記や場所が異なります）。
2. 表示されている専用メールアドレスをコピーします。

### 3. 拡張機能に登録

1. 拡張機能アイコンを右クリック→「オプション」を開く。
2. コピーしたメールアドレスを貼り付けて「保存」。
3. 「テスト送信」を押すと、テスト用の件名・本文でメール作成画面が開きます。宛先が正しいか
   確認してください（実際に送信するとJourneyにテストエントリーが作成されます）。

以降、サイドパネルから「Journeyに送信」を押すと、その内容でメール作成画面が開きます。

## 送信されるデータ

- **件名**: タイトル欄の内容（省略可）
- **本文**: エディタの本文。太字は`**太字**`、斜体は`*斜体*`、箇条書きは`- 項目`、番号付き
  リストは`1. 項目`のようなMarkdown風の記号で表現されます（メールは基本的にプレーンテキスト
  のみのため、Journey側で装飾として解釈されるとは限りません）。

拡張機能自身がメールを送信することはありません。実際の送信はメールソフト側で行われ、
拡張機能はメール作成画面を開くところまでを担当します。

## ファイル構成

```
manifest.json     拡張機能の定義（Manifest V3）
background.js     サービスワーカー（サイドパネルの開閉挙動、mailto:を開く処理）
sidepanel.html/js/css  サイドパネルの簡易エディタUI
options.html/js/css    Journey投稿用メールアドレスの設定・テスト送信画面
common.js         共通定数・バリデーション関数
icons/            ツールバー用アイコン
```

## 制約事項

- 実際にメールが送信されたかどうかは拡張機能側から確認できません（メールソフトを開くところ
  までが拡張機能の役割です）。
- メール本文はプレーンテキストのため、Journey側で太字・斜体・箇条書きが装飾として反映される
  保証はありません。
- タグ・位置情報・天気・感情など、Journeyアプリ本来の高度な入力機能は扱っていません
  （タイトルと本文のみ）。
