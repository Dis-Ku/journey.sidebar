# Journey Sidebar

Edge のサイドバー機能廃止に伴う代替として、オンライン日記アプリ [Journey](https://journey.cloud/) を
画面端にドッキングした専用ウィンドウで開閉できるようにする、Chrome/Edge 用の拡張機能（Manifest V3）です。

## 主な機能

- ツールバーのアイコンをクリックすると、画面右端にドッキングした縦長のウィンドウで Journey が開きます。
  もう一度クリックすると閉じます（トグル動作）。
- 開くURLは設定画面から変更可能（既定値: `https://journey.cloud/app/timeline`）。
- 設定画面でURLを変更すると、ウィンドウを開いたままでも自動的に反映されます。

## なぜ「サイドパネル」への埋め込みではないのか

Chrome/Edge には拡張機能用の `sidePanel` API があり、当初はそこに `<iframe>` で Journey を
表示する実装を検討・試作しました。しかし Journey は自身が iframe 内で表示されていることを
JavaScript で検知すると、「You may have been clickjacked」という警告バナーを表示し、
編集ツールバーなどの機能を無効化する仕組みを持っています（`X-Frame-Options` や
`Content-Security-Policy` のようなHTTPヘッダーレベルの対策に加えて、アプリ側のコード自体が
アドレスバーとの不一致を検知して機能を止める作りになっています）。

このJS側の検知は、ブラウザが意図的に保護している `window.top` 等の仕組みに依存しており、
拡張機能側から安全に無効化する手段はありません（無理に回避しようとすると、Journeyが本来
ユーザーを守るために用意しているクリックジャッキング対策を掻い潜ることになり、実装として
不適切です）。

そのため本拡張機能では、Journey を **iframeに埋め込まず、通常の独立したブラウザウィンドウ**
として開き、それを画面の右端にドッキングするレイアウトで表示することで、サイドバーのような
使用感を実現しています。通常のトップレベルウィンドウとして開くため、Journey側の全機能が
問題なく動作します。

## インストール方法（開発者モードで読み込み）

1. このフォルダをダウンロード（またはクローン）します。
2. Edge または Chrome で `edge://extensions` （Chromeなら `chrome://extensions`）を開きます。
3. 右上の「開発者モード」を有効にします。
4. 「展開して読み込み（unpacked）」からこのフォルダを選択します。
5. ツールバーに表示されたアイコンをクリックすると、画面右端に Journey のウィンドウが開きます。

## 表示URLの変更

拡張機能のアイコンを右クリック→「オプション」から設定画面を開き、開きたいURLを入力して
保存してください。ログインページから始めたい場合や、地域・言語によってURLが異なる場合は
ここで調整できます。

## 制約事項

- ドッキングは拡張機能側でウィンドウの位置とサイズを画面右端・全高に指定することで実現して
  います。OSやブラウザの「常に最前面」機能とは異なるため、他のウィンドウを前面に出すと
  Journeyのウィンドウは隠れます（通常のウィンドウの重なり順に従います）。
- マルチモニター環境では、`system.display` 権限を使ってプライマリディスプレイの作業領域を
  取得し、その右端に配置します。

## ファイル構成

```
manifest.json     拡張機能の定義（Manifest V3）
background.js     サービスワーカー（ウィンドウの開閉・ドッキング位置の計算）
options.html/js/css   開くURLを変更する設定画面
common.js         共通定数（既定URL・ストレージキーなど）
icons/            ツールバー用アイコン
```
